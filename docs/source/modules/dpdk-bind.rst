dpdk-bind
=========

.. code-block:: text

   This module is intended to be imported to set some interfaces in DPDK mode. Technically, that only means
   binding NICs to the UIO driver.

   User can set the igb_uio tag to use igb_uio instead of uio_pci_generic

   Suggested usage example in your test (omit the prefixed "//" that prevent loop import here)

   //%import@client dpdk-bind NIC=0

   That will bind NIC 0 of the client node to uio_pci_generic and ensure pages are mounted
