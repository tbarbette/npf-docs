netmap-bind
===========

.. code-block:: text

   Insert the Netmap kernel module and network drivers for packet I/O.

   Un:doc:`load <modules/load>`s any DPDK UIO drivers (igb_uio, uio_pci_generic) first, then
   :doc:`load <modules/load>`s the Netmap kernel module and the Netmap-patched i40e and ixgbe
   network drivers.

   Requires the netmap dependency to be built. Runs as an init script.
